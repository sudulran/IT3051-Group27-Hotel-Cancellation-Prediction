# Dataset

## Hotel Booking Demand Dataset

This project uses the **Hotel Booking Demand Dataset** for academic purposes as part of the IT3051 – Fundamentals of Data Mining mini project.

### Original Authors

Nuno Antonio, Ana de Almeida, and Luis Nunes

### Original Publication

Antonio, N., de Almeida, A., & Nunes, L. (2019).  
*Hotel booking demand datasets*.  
Data in Brief, 22, 41–49.

DOI: https://doi.org/10.1016/j.dib.2018.11.126

### Dataset Distribution

The combined `hotel_bookings.csv` version used in this project was obtained from Kaggle:

https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand
